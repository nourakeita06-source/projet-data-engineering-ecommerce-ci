# \# Projet Data Engineering E-commerce CI

# 

# \## 1. Description du projet

# 

# Ce projet a pour objectif de mettre en place un pipeline de données permettant de collecter, transformer et analyser les données d’un site e-commerce en Côte d’Ivoire. Le pipeline ETL permet d’extraire les données brutes, de les nettoyer, de les transformer puis de produire des indicateurs clés de performance (KPI) pour l’analyse.

#

# 

# \## 2. Architecture du pipeline

# 

# Schéma du pipeline :

# 

# Sources de données

# ↓

# Extraction des données (Python/Pandas)

# ↓

# Transformation et nettoyage des données

# ↓

# Chargement des données traitées

# ↓

# Analyse et calcul des KPI

# ↓

# Visualisation des résultats

# 

# \## 4. Structure du projet

# 

# \* `PROJET\_FINAL\_DATA\_ENGINEERING.ipynb` : pipeline ETL complet.

# \* `données/` : fichiers de données utilisés.

# \* `dags/` : DAG Airflow contenant les tâches automatisées.

# \* `Dockerfile` : configuration de l’environnement Docker.

# \* `docker-compose.yml` : orchestration des services.

# \* `requirements.txt` : dépendances Python du projet.

# \## 5. Instructions pour exécuter le projet

#
